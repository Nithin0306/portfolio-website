GroupFlix

Movie recommendation

Overview

Picking a film when a group of friends gathers often leads to decision fatigue. GroupFlix creates synced virtual rooms where members cast votes and preferences, calculating an optimal consensus choice without spoiler friction.

Highlights

  • Engineered a multi-user preference intersection algorithm with anti-veto threshold filtering.
  • Implemented real-time room synchronization for participants across mobile and desktop browsers.
  • Integrated TMDB API with genre clustering and popularity curve normalization.

LEVEL 1-3

FishGlob

Current-aware fish analysis

Overview

Traditional marine fisheries analysis ignores the impact of shifting ocean currents. FishGlob correlates hydrodynamic telemetry data with historical fish catch distributions to identify feeding zones and migration corridors.

Highlights

  • Analyzes sea surface temperatures, chlorophyll-a density, and directional current velocities.
  • Predicts high-density pelagic fish corridors with 87% validation accuracy against sample datasets.
  • Visualizes vector velocity fields over oceanographic geospatial coordinate grids.

Stack

Python Data Analysis NumPy Geospatial Mapping
