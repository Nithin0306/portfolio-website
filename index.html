GoCDC

High-Throughput Event-Driven Change Data Capture Pipeline

Overview

Database polling creates massive overhead in high-throughput microservices. GoCDC taps directly into PostgreSQL's Write-Ahead Log (WAL) via logical replication to stream mutations asynchronously into Apache Kafka with zero query overhead on the source database.

Key Highlights

  • Engineered a Go-based CDC engine utilizing PostgreSQL WAL logical decoding, streaming DML events to Redpanda at 1,400 events/sec.
  • Architected a fault-tolerant polyglot persistence pipeline routing data from Postgres to Redis and MongoDB via Kafka with <150ms replication lag and zero data loss.
  • Containerized the 6-node microservice ecosystem using multi-stage Docker builds, reducing Go binary image sizes to 20MB.

Stack

Go (Golang) PostgreSQL WAL Apache Kafka Redis MongoDB Docker
